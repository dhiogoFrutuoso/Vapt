# Builds oficiais

Esta pasta contém os instaladores assinados do Vapt que serão espelhados em
[`Vapt-Releases`](https://github.com/dhiogoFrutuoso/Vapt-Releases). Os nomes
dos arquivos devem permanecer estáveis: `vapt.apk` e `vapt-setup.exe`.

Não coloque senhas, keystores ou arquivos `.env` aqui. Consulte
[`releases/README.md`](../releases/README.md) antes de publicar uma nova versão.
